What stands out

Read straight off the rows in view — change a filter and these change with it. Each one names the figure it came from, so it can be checked against the tables below rather than taken on trust. Comparisons of collection rate run over money that has already fallen due, so a batch whose instalments are still months away is never called a poor performer for money nobody has asked for yet.
